# 首页 Token 用量统计

## 范围

首页复用现有 `GET /api/requests/stats`，不新增统计接口、不引入费用计算。

- 时间窗口：最近 24 小时、7 天、30 天。
- 汇总：请求总数、成功/失败/取消数、Token 总量、输入/输出 Token、成功率、平均延迟。
- 来源拆分：
  - `upstream_usage`：远程 Provider 返回的 usage。
  - `llama_timings`：本地 llama.cpp timings 统计。
  - `unknown_source`：来源无法确认的旧记录或其他来源。
- 首页加载时读取一次；后台轮询期间低频刷新；用户可手动刷新或切换窗口。
- 所有请求通过 Web Session 调用管理 API。

## 解释边界

- Token 总量是三个来源分组的合计，来源未知的记录会单独显示，不能误认为上游供应商 usage。
- `llama_timings` 是本地引擎统计，不等同于供应商账单用量。
- 没有 Token 字段的请求仍计入请求数，但不计入各来源的 Token 请求数。
- 当前统计按请求开始时间归属时间窗口，遵循 API 的 [from, to) 边界。
- 新请求在最终请求记录中同步保存 Token 来源，避免分析 JSON 异步写入失败导致来源误归类；历史记录继续回退读取分析 JSON。
- 不展示费用，不使用模型价格表推算金额。

## 验收

- 未登录时不发起统计请求；登录后首页加载统计。
- 切换 24h/7d/30d 会请求对应窗口。
- 统计接口失败时显示错误，不伪造 0 用量。
- 桌面和窄屏布局均可查看来源表格；窄屏表格允许横向滚动。
