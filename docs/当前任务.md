## 1. 目标

建立本地模型运行时快照，并把它作为 RequestAnalysis 的独立证据层。快照用于解释请求发生期间附近的模型/CPU运行状态，但不能伪装成请求瞬时硬件状态。

## 2. 当前实现

- 后台独立 RuntimeSnapshot sampler。
- 默认 5 秒采样一次。
- Server shutdown 等待 sampler 退出。
- 本地 Provider 才采集；远程 Provider 不伪造本机资源。
- 复用已有 RuntimeSnapshot cache，Ollama 优先 memory-only 路径。
- Snapshot 保存 source/status/sampled_at。
- 请求侧读取不可变副本。
- 超过 15 秒的快照标记 unavailable。
- CPU 快照缺失时标记 partial。
- RequestAnalysis 已增加 runtime_snapshot。
- OpenAPI 已同步 runtime_snapshot Schema。
