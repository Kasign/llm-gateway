## 1. 目标

基于官方来源核验候选厂商的免费 API 计划，形成可比较的候选矩阵，为 FREE-03 免费政策元数据结构和 FREE-06 首个 Provider 选择提供事实依据。

本任务不实现 Provider Adapter，不新增目录 API，不配置或保存任何真实 API Key，也不根据聚合平台/第三方文章推断官方免费额度。

## 2. 候选范围

沿用《产品能力技术方案》已列候选集合：

- Google AI Studio / Gemini API
- GroqCloud
- Cerebras Inference
- Cloudflare Workers AI
- OpenRouter
- Hugging Face Inference Providers

不得在取得官方政策证据前提前选定首个 Provider。若官方政策不存在、已结束或地区/账户条件不清楚，必须如实标记，不用“免费”营销描述代替实际额度。

## 3. 每个候选必须核验

1. 官方免费计划当前是否有效，官方文档/价格页/政策公告 URL 和核验日期。
2. 注册与 API 使用的地区限制、账号类型、组织认证要求。
3. 是否要求绑定支付方式、手机号或其他验证。
4. 免费额度类型与周期：每日、每分钟、每月、试用额度或按模型单独限制。
5. 免费请求数、输入/输出 Token、RPM、TPM、并发和速率限制；官方未明确的字段记为未知，不填 0。
6. 官方 API Base URL、鉴权方式、模型 ID 和接口协议。
7. Chat Completions、Responses、Anthropic Messages、Streaming、Tool Calling、Vision、Structured Output 等能力的官方支持证据。
8. 额度耗尽时的 HTTP 状态码、错误类型、Retry-After 或官方说明；未找到证据则记未知。
9. 服务条款是否允许通过个人 Gateway 代理转发，是否存在用途、地区或商业使用限制。
10. 官方信息最后核验时间及需要复核的日期/触发条件。

## 4. 证据与状态规则

- 只把厂商官方文档、官方价格页、官方控制台说明和官方公告作为政策事实依据。
- 第三方比较文章、模型聚合目录和社区帖子只能用于发现线索，不作为免费额度结论依据。
- 区分“官方明确免费”“免费层有条件/有速率限制”“试用/促销”“付费服务有免费试用额度”“官方信息不足”“已失效”。
- 不把模型开源、可下载或有免费网页聊天入口等同于免费 API。
- 不把 Gateway 自身的 RPM/Token Budget 当成厂商免费余额。
- 对地区、绑卡、额度耗尽语义等无法从官方来源确认的内容，标记未知并保留来源缺口。

## 5. 首个 Provider 选择原则

只有完成候选比较后才建议首个 Provider。优先考虑：

- 官方免费政策持续有效、规则清晰；
- 用户注册和使用地区适用性明确；
- 官方 API 能由现有 OpenAI-compatible Adapter 表达；
- 模型 ID 和模型能力有官方依据；
- 免费额度耗尽能被可靠识别；
- 不要求自动付费、隐式回退或不透明的信用额度操作。

FREE-06 仍须通过真实短请求验收；本任务的政策调研不能替代 API 实测。

## 6. 验收标准

- 候选厂商逐家有官方来源和核验日期。
- 地区、账号、绑卡、额度周期、RPM/TPM、模型范围均有明确值或明确未知状态。
- 协议能力和额度耗尽语义有官方证据或明确标记未验证。
- 形成横向对比与首个 Provider 建议，解释取舍和风险。
- 未把任何未验证候选标记为当前可用，也未提交真实密钥。
