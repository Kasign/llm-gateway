# 任务历史归档

本目录保存已完成任务的完整执行记录，供后续追溯。历史文档不维护当前任务状态，也不自动构成新的待办。

## 归档规则

1. 只有任务达到《整体任务规划》中的验收条件后才能归档。
2. 归档前，将《当前任务.md》完整复制为本目录对应文件，保留任务目标、实施过程、问题处理、提交、CI、测试和真实环境验收证据。
3. 在《整体任务规划.md》中将任务标记为“已完成”，并关联对应历史文件。
4. 同一批文档变更中，将《当前任务.md》更新为下一项任务。
5. 历史记录不得覆盖或反向修改当前任务状态；发现历史记录错误时追加更正说明，保留原始证据。

## 命名规范

使用“任务编号-中文任务名.md”，例如：

- `TOOL-01-现状盘点与协议验证.md`
- `TOOL-02-Tool-Definition与Registry.md`
- `PERF-01-现有字段与timings盘点.md`

按阶段建立子目录：`工具能力/`、`Benchmark体系升级/`、`本地模型分析/`、`免费模型聚合/`。只有实际归档任务时创建相应文件。
